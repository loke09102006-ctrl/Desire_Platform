# Desire — Venture Funding Platform v2

## Upgrades
- Fully role-based UI: Investor vs Startup Founder
- Investor: Dashboard, Discover Startups, Deal Pipeline, Meetings, Messages, Billing
- Startup: Founder Dashboard, Startup Profile Editor, Pitch Upload, Meetings, Messages, Billing
- New premium dark gold aesthetic with Lora + Syne + DM Mono fonts
- Payment/Billing section with plan comparison for both roles
- Pitch deck upload with progress bar simulation
- Team member management for startup profiles
- Metric cards for both investor and founder dashboards
- Improved meeting flow with Accept/Decline buttons

## Running
```bash
pip install -r requirements.txt
python app.py
```
Visit http://localhost:5000 · Use demo buttons or register.
